Desk Buddy

Flash it straight from your browser

ESP32-C3 12 faces Touch Piezo
This browser can't talk to serial devices — use desktop Chrome, Edge or Opera. This page must be served over HTTPS or from localhost.

Erases the flash and writes the firmware plus the on-device control panel.

Before you start

  1. Use a real data USB-C cable — plenty of charge-only cables carry no data lines.
  2. Plug the board in. The C3 uses its built-in USB-Serial/JTAG, so no driver install is needed.
  3. Open this page in desktop Chrome or Edge — Firefox and Safari have no Web Serial.
  4. Hit Install firmware and pick the serial port that appears.

First boot

  1. The buddy shows its face and chirps a four-note jingle on the piezo.
  2. It starts a WiFi access point called DeskBuddy-Setup.
  3. Join it — the setup sheet should pop up automatically, otherwise browse to http://192.168.4.1.
  4. Enter your home WiFi details and the buddy reboots onto your network.
  5. Open the control panel at http://buddy.local.

Using it

  1. Single tap the touch pad to cycle through all twelve faces.
  2. Hold the touch pad for about 0.7 s to show the message you typed in the control panel, along with the message melody.
Building this page yourself? The installer needs desk-buddy-firmware.bin and littlefs.bin sitting next to it, described by manifest.json. Generate all three with ./tools/build_release.sh, then serve the folder over HTTPS — Vercel or GitHub Pages both work.
Firmware flashed this way already includes the control panel in LittleFS, so there is nothing else to upload.
