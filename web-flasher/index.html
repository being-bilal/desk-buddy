Desk Buddy

ESP32-C3 Super Mini · 5 animated faces · capacitive touch · piezo audio

This browser can't talk to serial devices. Use desktop Chrome, Edge or Opera. This page must be served over HTTPS or from localhost.

Erases the flash and writes the firmware plus the on-device web panel.

Before you start

  1. Use a real data USB-C cable — many charge-only cables carry no data lines.
  2. Plug the ESP32-C3 Super Mini in. The C3 uses its built-in USB-Serial/JTAG, so no driver install is needed.
  3. Open this page in desktop Chrome or Edge (Firefox and Safari have no Web Serial).
  4. Click Install firmware and pick the serial port that appeared.

After installing

  1. The buddy boots, shows its face and chirps a short four-note jingle on the piezo.
  2. On first boot it starts a WiFi access point called DeskBuddy-Setup.
  3. Join that network — the setup sheet should pop up automatically, otherwise browse to http://192.168.4.1.
  4. Enter your home WiFi details and the buddy reboots onto your network.
  5. Open the control panel at http://buddy.local.

Using it

  1. Single tap the touch pad to cycle through the five faces.
  2. Hold the touch pad for about 0.7 s to show the message you typed in the control panel; track 2 plays with it.
Build this page yourself? This installer needs desk-buddy-firmware.bin and littlefs.bin next to it, described by manifest.json. Generate all three with ./tools/build_release.sh, then serve the folder over HTTPS (GitHub Pages works well) or localhost.
Firmware flashed this way includes the web panel in LittleFS, so there is nothing else to upload.
